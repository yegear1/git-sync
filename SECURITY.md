# Security Policy

## Supported Versions

We provide security updates for the following versions of `git-sync`:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability in `git-sync`, please **do not** open a public issue.

Instead, please report the vulnerability through one of the following channels:

1. **GitHub Private Vulnerability Reporting:**
   Use the "Report a vulnerability" button on the [Security Advisory page](https://github.com/yegear1/git-sync/security/advisories).
2. **Direct Contact:**
   Contact the maintainers via GitHub or email at `yegear1@users.noreply.github.com`.

### What to Include

Please provide as much information as possible to help us reproduce and resolve the issue:
- A description of the vulnerability and its potential impact.
- Clear steps to reproduce or a minimal proof of concept (PoC).
- Your operating system, Python version (`python3 --version`), and Git version (`git --version`).

### Response Timeline

- **Initial Response:** Within 48 hours acknowledging receipt of the report.
- **Triage & Assessment:** Regular updates regarding validation, patch development, and estimated release date.
- **Public Disclosure:** Coordinated disclosure after a fix has been verified and released.
